# Portfolio Website

Personal portfolio website for UX/UI design and frontend projects.

## About

This project is a personal portfolio created to showcase:
- UX/UI design case studies
- Figma prototypes
- frontend projects
- website redesigns
- visual design work

The portfolio includes project pages, case study descriptions, images, galleries, and responsive layouts.

## Tech Stack

- Next.js
- React
- CSS Modules
- JavaScript
- HTML
- CSS
